# Детекция аномалий в налоговых декларациях: сравнение методов без учителя

Код к статье «Применение методов машинного обучения для детекции аномалий в налоговых декларациях»
(Дубанаев З. М., научный руководитель Искаков Р. Т., КГТУ им. И. Раззакова). Статья готовится к публикации.

*Anomaly detection in tax declarations: a reproducible comparison of unsupervised methods (Isolation Forest,
LOF, One-Class SVM, autoencoder, ensemble) on synthetic data modelled on corporate tax declarations of the
Kyrgyz Republic.*

## Важно: данные синтетические

Реальные данные налогоплательщиков не используются. Генератор воспроизводит структуру полей Единой
налоговой декларации организаций КР (форма STI 101), но его параметры заданы экспертно и **не
откалиброваны** по реальным данным ГНС КР. В данные внедряются аномалии трёх типов (2,1 % деклараций):

- точечное искажение одной строки декларации;
- завышение входного НДС (имитация фиктивных ЭСФ);
- занижение фонда оплаты труда при неизменной численности.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python experiments.py
```

Полный прогон занимает несколько минут. Все случайные значения фиксированы, поэтому результаты
воспроизводятся точно. То же самое можно выполнить по ячейкам в `experiments.ipynb`.

## Основные результаты

Среднее по 5 запускам, порог — верхние 3 % деклараций по оценке аномальности.

| Метод | НДС: F1 / ROC-AUC | Налог на прибыль: F1 / ROC-AUC | Смешанный: F1 / ROC-AUC |
|---|---|---|---|
| LOF | 0,270 / 0,867 | 0,305 / 0,876 | 0,164 / 0,832 |
| Автокодер | 0,259 / 0,864 | 0,243 / 0,859 | 0,145 / 0,842 |
| Ансамбль (среднее) | 0,223 / 0,830 | 0,256 / 0,851 | 0,139 / 0,814 |
| One-Class SVM | 0,136 / 0,727 | 0,161 / 0,750 | 0,109 / 0,738 |
| Z-скоринг (бенчмарк) | 0,116 / 0,583 | 0,111 / 0,608 | 0,139 / 0,607 |
| Isolation Forest | 0,043 / 0,596 | 0,041 / 0,613 | 0,024 / 0,617 |

LOF и автокодер, учитывающие совместное расположение признаков, работают лучше всего. Isolation Forest
близок к случайному ранжированию: внедрённые аномалии нарушают соотношения между показателями, а не дают
экстремальных значений отдельных признаков. Ансамбль с равными весами выигрыша не даёт.
